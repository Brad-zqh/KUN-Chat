# 坤坤 AI 同人人格素材库

本目录用于构建一个明确标注、可与真人区分的 AI 同人角色。素材仅来自公开可访问页面；项目保存来源元数据、事实核验结果和转述摘要，不镜像整篇文章或整段受版权保护视频。

- `sources.md`：来源、时间、可靠性与可提取主题
- `style-synthesis.md`：跨来源风格综合与禁止推断项
- `few-shot.md`：基于综合规则创作的合成对话，不是真人原话
- `rag-platform.md`：DeepSeek API、本地增量 RAG 与网页接线说明

## 本地聊天入口

- 地址：`http://127.0.0.1:8766/chat.html`
- 支持：坤坤 AI 同人 / 峰哥 AI 切换、文字输入、浏览器语音输入、增量 RAG、来源链接、VoxCPM/MiniMax TTS、分角色保存本地聊天记录。
- 文字模型：可切换 MiniMax 或 DeepSeek；在 `.env.local` 中填写对应 API Key 后重启网页服务。
- 页面与回复始终保留“AI 同人、非本人”标识。当前坤坤 TTS 使用用户声明已获本人许可后创建的 MiniMax Voice ID；授权记录、Voice ID 与克隆源样本仅保存在本机，不随仓库发布。
- 账号、积分和 Stripe 充值的服务端设计见 `credits-auth-plan.md`；在支付密钥与公网回调地址配置完成前，不显示假的充值成功状态。
